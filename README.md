# Snake Game Web

이 프로젝트는 Helpy Chat과 Github MCP를 활용하여 자동화된 방식으로 생성된 웹 기반 스네이크 게임입니다.

## 소개
- HTML & JavaScript로 만들어진 간단한 Snake 게임입니다.
- 벽 충돌, 재시작 버튼, 속도 조절(이지/노말/하드/헬), 점수 랭킹 TOP 5 기록(브라우저 LocalStorage) 등 다양한 기능을 제공합니다.

## 주요 특징
- Helpy Chat(헬피)와 Github MCP를 통해 자동화된 코드 생성 및 배포
- 누구나 쉽게 실행하고 수정할 수 있는 구조
- 초보자도 이해하기 쉬운 코드와 설명

## 실행 방법
1. 레포지토리를 클론합니다.
   ```bash
   git clone https://github.com/jihyunryu1215-rgb/snake-game-web.git
   cd snake-game-web
   ```
2. Python 웹 서버로 실행합니다.
   ```bash
   python3 -m http.server 8000
   ```
3. 브라우저에서 아래 주소로 접속합니다.
   http://localhost:8000

## 사용 기술
- HTML5, CSS3, JavaScript(ES6)
- Helpy Chat(코드 자동화)
- Github MCP(자동 배포)
